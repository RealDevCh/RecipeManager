# RecipeManager v1.8.2 (통합 구조 · 스프레드시트 표 & 깔끔한 달력 개편)

## 🛠️ v1.8.2 주요 개선 내역
1. **실제 스프레드시트형 할 일 표 (`st.data_editor`) 적용**:
   - 여러 컬럼을 쪼개 붙이던 방식 대신 단일 스프레드시트 그리드로 교체해 한 줄 정렬·테두리·체크박스(`이동`)·행 클릭 우측 세부정보 연동이 깔끔하게 동작합니다.
2. **달력 UI 및 제목 정돈**:
   - 달력 제목을 **`📅 2026년 11월`** / **`📅 2026년 11월 16일 ~ 11월 22일`** / **`📅 2026년 11월 18일 (수)`**로 깔끔하게 수정했습니다.
   - 빈 날짜 칸에 찍히던 `-` 기호를 제거하고, 전월/익월 날짜(`10/26`~`10/31`)까지 7열 그리드로 빈칸 없이 채웠으며, 일정 버튼 텍스트가 셀 테두리 밖으로 삐져나가지 않도록 말줄임(`...`) 처리했습니다.
