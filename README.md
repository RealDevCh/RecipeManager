# RecipeManager v1.8.0 (통합 구조 · GitHub/모바일 배포 최적화)

`pages/` 하위 폴더 없이 **루트 디렉터리 파일 3개(`app.py`, `database.py`, `requirements.txt`)만으로 GitHub 및 Streamlit Cloud에 즉시 배포할 수 있는 통합 구조 패키지**입니다.

## ✨ v1.8.0 주요 개선 내역 (`✅ 할 일` 및 절충안 달력 완성)
1. **표 상단 우선순위 이동 & 체크박스 상태 유지 (`move_checked_todos`)**:
   - 표 바로 위에 **`▲ 위로` / `▼ 아래로` / `⏫ 최상단` / `선택 해제`** 버튼 바를 배치했습니다.
   - 체크박스는 우선순위 이동 전용으로 동작하며, 위·아래로 여러 번 이동해도 체크 표시가 풀리지 않고 항목을 따라 유지됩니다.
   - 각 행의 **할 일 키워드를 클릭**하면 우측 패널에 세부정보가 표시됩니다.
2. **전방위 통합 검색 (`get_todos_enriched` & `filter_todos_by_query`)**:
   - 표에 표시되지 않는 **Lot ID, 의뢰 부서, 의뢰자, Product, Step, 설비(Equipment), 세부 내용, 등록일시, 상위/하위 업무명, 첨부 이미지 파일명, 연관 레시피 변경 이력**까지 항목과 관련된 모든 정보를 한 번에 검색합니다.
   - 비노출 필드에서 매칭된 경우 해당 행 아래에 `🔎 Lot ID: LOT-26A01` 형태로 매칭 근거를 표시합니다.
3. **절충안 달력 UI (상단 마일스톤 로드맵 바 + 100% 풀폭 달력 + 클릭 상세 모달)**:
   - 상단 로드맵 바에서 `🎯 큰 납기` 진행률을 확인하고 클릭 시 해당 큰 일에 속한 일정만 달력에 필터링합니다.
   - 하단 100% 풀폭 달력(월간/주간/일간)에서 일정을 클릭하면 세부정보 수정 모달(`@st.dialog`)이 열립니다.

## 🚀 GitHub 웹/모바일 업로드 방법 (단 3개 파일)
1. GitHub 저장소(`RealDevCh/RecipeManager`) 루트 경로에 아래 **3개 파일**을 덮어쓰기 업로드합니다.
   - `app.py`
   - `database.py`
   - `requirements.txt`
2. 기존 백업 ZIP 파일이 있다면 `🛠️ 기준정보 및 백업` 탭에서 복원 시 v1.8.0 스키마로 자동 마이그레이션됩니다.
