# RecipeManager v1.8.1 (통합 구조 · 반응형 할 일 표 레이아웃 수정)

## 🛠️ v1.8.1 긴급 레이아웃 패치 내역
- **할 일 표 깨짐(줄바꿈·잘림) 수정**: 좌측 패널(58% 폭) 내부에 8개의 좁은 컬럼(`st.columns`)을 중첩해 헤더(`순서`, `긴급도`, `담당자`)가 세로로 꺾이고 날짜가 잘리던 문제를 **반응형 3컬럼 구조(`[이동 체크박스] | [순서·긴급도·키워드] | [기한·상태]`)**로 개편하여 어떤 화면 폭에서도 표가 깨지지 않도록 개선했습니다.
- **우선순위 이동 바 & 달력 내비게이션 줄바꿈 방지**: 모든 버튼에 `white-space: nowrap` 및 넉넉한 컬럼 비율을 적용해 글자가 세로로 꺾이지 않습니다.
