# RecipeManager v2.2.1 (이전 st.dataframe 표 복원 · 행 클릭 상세보기 & 우선순위 이동)

## 🛠️ v2.2.1 수정 내역
1. **이전 스프레드시트 표(`st.dataframe`) UI로 깔끔하게 복원**:
   - 셀마다 버튼이 생기던 커스텀 그리드를 제거하고, 기존에 호평받으셨던 깔끔한 `st.dataframe` 표로 되돌렸습니다.
   - 별도의 `선택` 텍스트 컬럼 없이 `순서`, `긴급`, `구분`, `할 일 키워드`, `목표기한`, `의뢰부서`, `담당자`, `상태` 컬럼만 컴팩트하게 표시됩니다.
2. **행 클릭 상세보기 & 표 위 우선순위 이동**:
   - 표에서 원하는 행을 클릭하면 행 전체가 파란색으로 강조되면서 우측 세부정보 패널이 즉시 전환됩니다.
   - 표 바로 위의 `▲ 위로` / `▼ 아래로` / `⏫ 최상단` 버튼으로 선택한 행의 순서를 이동할 수 있으며, 이동 후에도 선택한 행의 파란색 강조가 그대로 유지됩니다.

## 🚀 GitHub / Streamlit Cloud 업데이트 방법
- 루트 경로의 **`app.py`**, **`todo_view.py`**, **`database.py`**, **`other_views.py`**, **`requirements.txt`** 5개 파일을 덮어쓰기 업로드하면 바로 반영됩니다.
