# RecipeManager v2.2.2 (상단 흰색 헤더 박스 제거 & 체크박스 없는 한 행 클릭 선택 표)

## 🛠️ v2.2.2 수정 내역
1. **상단 흰색 헤더 박스(`stHeader`) 투명화**:
   - 본문 상단 리본 바(`RecipeManager Workspace`) 위를 덮던 흰색 헤더 박스를 투명하게 처리하고 상단 여백을 조정해 리본 바가 깔끔하게 보이도록 수정했습니다.
2. **체크박스 없이 행(가로 한 줄) 클릭만으로 행 전체 파란색 강조 + 상세보기 + 우선순위 이동**:
   - Streamlit 기본 `st.dataframe`은 `selection_mode="single-row"` 사용 시 좌측 체크박스가 강제 생성되고 일반 셀 클릭은 셀 포커스만 바뀌는 구조적 제약이 있습니다.
   - 이를 대체하여 버튼 테두리나 체크박스가 전혀 없는 스프레드시트형 행 그리드를 적용했으므로, **행의 어느 칸을 클릭하든 해당 행 전체가 파란색으로 강조**되며 우측 세부정보 전환과 상단 `▲ 위로` / `▼ 아래로` / `⏫ 최상단` 이동이 동시에 동작합니다.
