# RecipeManager v2.2.0 (체크박스 제거 · 한 행 전체 선택 테이블 통일)

## ✨ v2.2.0 주요 개선 내역
1. **테이블 체크박스 완전 제거 & 한 행 전체 선택 방식 적용**:
   - `st.dataframe`의 셀 단위 포커스 및 좌측 체크박스 컬럼을 제거하고, **한 행(가로 전체) 단위로 선택·하이라이트되는 테이블**로 교체했습니다.
   - 행의 어느 위치를 클릭하든 **해당 행 전체**가 선택되며, 우측 세부정보 패널 전환과 상단 우선순위 이동(`▲ 위로` / `▼ 아래로` / `⏫ 최상단`)이 동시에 연동됩니다.
   - 순서를 위·아래로 이동해도 선택한 행의 하이라이트가 그대로 따라 움직입니다.
2. **컴팩트 컬럼 폭 & 전체 기능 유지**:
   - `순서`, `긴급`, `구분` 컬럼 폭을 최소화하고, 새 할 일 등록 모달(`Module`, `Purpose`, `Recipe` 포함 · 모든 란 공란 가능 · 제목 소실 및 `Ctrl+V` 중복 등록 수정)과 달력 뷰(상단 마일스톤 바 + 7열 심리스 그리드 + 우측 드로어)가 동일하게 동작합니다.
