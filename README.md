# RecipeManager v2.0.0 (MS Office Fluent 디자인 통합 & 모듈 리팩토링)

## ✨ v2.0.0 주요 개선 및 리팩토링 내역
1. **MS Office Fluent UI 디자인 시스템 통일 & 코드 모듈 분리**:
   - `app.py`(메인 엔트리·Fluent 테마), `database.py`(DB·검색·우선순위·Diff·백업), `todo_view.py`(할 일 표·모달·달력), `other_views.py`(레시피 확인·등록·횡전개·기준정보) 4개 모듈로 깔끔하게 리팩토링했습니다.
   - 상단 Office 리본 헤더와 실시간 테마 전환(`MS Office 블루 / 그린 / 슬레이트`)을 지원합니다.
2. **할 일 표 개선 (`st.dataframe` 단일 행 선택 + 표 위 우선순위 조정)**:
   - 표 위(`▲ 위로` / `▼ 아래로` / `⏫ 최상단`) 버튼으로 선택 항목의 순서를 즉시 조절하며, 선택한 항목의 `☑` 표시와 하이라이트가 이동한 위치에도 그대로 유지됩니다.
   - 표의 행(한 줄)을 클릭하면 우측 세부정보 패널이 즉시 전환됩니다.
   - 표에 보이지 않는 `Lot ID`, `의뢰 부서`, `의뢰자`, `세부 내용`, `첨부파일명`까지 전방위 통합 검색됩니다.
3. **달력 UI (시안 B 풀폭 심리스 7열 격자 + 우측 드로어 & 시안 C 상단 마일스톤 바)**:
   - 상단 로드맵 바에서 `큰 납기`별 진행률을 확인하고 클릭 시 해당 프로젝트 일정만 달력에 필터링합니다.
   - 평소에는 100% 전체 폭의 깔끔한 7열 격자 달력으로 표시되며, 일정 칩 클릭 시 우측 세부정보 패널이 열리고 `닫기` 클릭 시 다시 100% 폭으로 복귀합니다.
