# RecipeManager v2.1.0 (버그 수정 + Module/Purpose/Recipe 추가 + 테이블 컴팩트화)

## 🛠️ v2.1.0 수정 및 개선 내역
1. **[버그 수정] 새 할 일 등록 시 제목(키워드) 소실 문제 해결**:
   - `st.text_input(key="dlg_title")` 및 세션 상태 보존 로직(`smart_combobox`)을 적용하여 입력 도중이나 다른 항목 조작 시에도 제목과 모든 입력값이 사라지지 않습니다.
2. **[버그 수정] 증빙 이미지 `Ctrl+V` 무한 중복 등록 해결**:
   - 붙여넣기 버튼 키에 동적 논스(`nonce`)를 부여하여 1회 붙여넣기 시 정확히 1장만 등록되고 즉시 초기화됩니다.
3. **Module, Purpose, Recipe 입력 추가 & 모든 란 공란 등록 허용**:
   - 새 할 일 등록 및 우측 세부정보 수정 화면에 `Module`, `Purpose`, `Recipe`(등록된 Handler/Vision 목록 연동 + 직접입력)를 추가했습니다.
   - 제목, 담당자, 목표기한을 포함한 **모든 란이 공란 상태로 등록·수정 가능**합니다.
4. **할 일 테이블 컴팩트화 & 행 선택 기반 상세보기·우선순위 이동**:
   - 불필요한 `선택` 컬럼을 제거하고 `순서`, `긴급`, `구분` 컬럼 폭을 최소화했습니다.
   - 테이블에서 항목 한 줄을 클릭하면 우측 상세보기 패널이 즉시 전환되며, 표 위 `▲ 위로` / `▼ 아래로` / `⏫ 최상단` 버튼으로 선택한 항목의 우선순위를 바로 이동할 수 있습니다.
