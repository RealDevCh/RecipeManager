# RecipeManager v1.7.0 (통합 구조 · GitHub/모바일 배포 최적화)

`pages/` 하위 폴더 없이 **루트 디렉터리 파일 3개(`app.py`, `database.py`, `requirements.txt`)만으로 GitHub 및 Streamlit Cloud에 즉시 배포할 수 있는 통합 구조 패키지**입니다.

## ✨ v1.7.0 주요 개선 내역 (`✅ 할 일` 고도화)
1. **표(Table) 기반 목록 & 원클릭 세부정보**: 항목 하단의 '세부 정보 보기' 버튼을 제거하고, 표의 행을 직접 클릭하면 우측 세부정보 패널이 즉시 연동됩니다.
2. **모달 등록 창 (`@st.dialog`) 분리**: 바깥 영역을 클릭해도 닫히지 않는 중앙 모달 등록 창을 적용하고, 우측 세부정보 수정 영역과 위치를 완전히 분리했습니다.
3. **신규 등록 폼 고도화**:
   - 증빙 이미지 **N개 다중 첨부** (다중 파일 선택 + `Ctrl+V` 연속 붙여넣기)
   - **의뢰 부서 (`Department`)** 기준정보 CRUD 연동 및 자동완성
   - **의뢰자**, **Lot ID** 입력 및 과거 입력 이력 자동 기억·자동완성
   - 모든 콤보박스의 **직접 입력 + 기존 값 자동완성** 지원
   - **목표 기한** 달력 UI (`st.date_input`, 기본값 오늘)
   - **담당자** 기본값 `유철형` 자동 지정 및 **등록일시 (KST)** 자동 기록
4. **일 / 주 / 월 계층형 달력 UI**: `🎯 납기(큰일)` ↔ `⚡ 실행(소규모)` 연결 구조를 지원하며, 달력에서 일간·주간·월간 전환 및 계층별 필터링을 제공합니다.
