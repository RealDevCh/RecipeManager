# RecipeManager v1.9.0 (통합 구조 · 시안 B+마일스톤 달력 & 한 줄 선택 할 일 표)

## ✨ v1.9.0 주요 개선 내역
1. **달력 UI (시안 B 풀폭 심리스 그리드 + 우측 세부정보 드로어 & 시안 C 상단 마일스톤 바)**:
   - 날짜 칸 사이의 붕 뜬 여백과 두꺼운 테두리를 제거하고 심리스 7열 헤어라인 그리드와 슬림 컬러 이벤트 칩을 적용했습니다.
   - 평소에는 달력이 100% 전체 폭으로 넓게 펼쳐져 있으며, 일정 칩을 클릭하면 우측에 세부정보 편집 드로어가 열리고 `✕ 닫기` 시 다시 100% 폭으로 복귀합니다.
2. **할 일 표 개선 (단일 체크박스 + 한 줄 클릭 선택 + 하단 콤보박스 제거)**:
   - 우선순위 이동 체크박스는 **한 번에 1개만** 체크되도록 동작하며, 위·아래 이동 시 체크 표시가 유지됩니다.
   - 셀별 선택이나 하단 콤보박스 없이, 표에서 **항목 한 줄을 클릭**하면 해당 줄 전체가 하이라이트되고 우측 세부정보 패널이 즉시 전환됩니다.
